# Vibe Code Editor

A browser-based code editor supporting HTML, CSS, JS, Vue, and Svelte 
with real-time preview, authentication, and project saving.

## Tech Stack
- Next.js 14 + TypeScript
- Prisma + MongoDB
- NextAuth (authentication)
- shadcn/ui + Tailwind CSS
- Deployed on Vercel

## Features
- Multi-language code editing
- User authentication & saved projects
- Real-time preview
- [Live Demo](https://vibe-code-editor-vishal-bhardwaj.vercel.app)

## Run Locally
\`\`\`bash
git clone ...
npm install
npm run dev
